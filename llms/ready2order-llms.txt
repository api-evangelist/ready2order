# ready2order Public API

> ready2order is an Austrian cloud point-of-sale (POS) system for small businesses in gastronomy, retail, and services. Its Public API (v1) lets integrations manage products, orders, bills/invoices, customers, tables, coupons, payments, and printing, with webhook events for real-time sync. Tax-office compliant for Austria, Germany, and Switzerland.

## API

- [ready2order Public API v1](https://ready2order.com/api/doc): REST API. Base URL https://api.ready2order.com/v1. Bearer Account Token auth (Authorization header). 140 operations across 37 resource groups. Rate limit 60 req/min per Account Token.
